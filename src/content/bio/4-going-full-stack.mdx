My work has crossed the stack: APIs in Go, front-end web in React and JavaScript, and native iOS in SwiftUI, with GraphQL, GitHub Actions and Bitrise holding it together. Jira and Confluence keep the people side organized.

I like building the same product from more than one side. Today's side projects, including a self-hosted spend tracker with a Go API, a React web app and a native Mac client, are how I keep every layer sharp.
