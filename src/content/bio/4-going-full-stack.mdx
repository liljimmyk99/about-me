My work has crossed the stack. At Penn State I built a custom Alexa Skill on AWS SAM, Lambda and DynamoDB, which was my first taste of full-stack and cloud development. At Ford I wrote React for in-vehicle hardware, then moved to native iOS in SwiftUI. Along the way I've picked up APIs in Go, GraphQL, and the pipelines that ship it all: GitHub Actions and Bitrise. Jira and Confluence keep the people side organized.

I like building the same product from more than one side. When I mentored Team 5401, I brought my mobile experience to the team's first scouting and team-management app. Today my side projects are how I keep every layer sharp. Penny-Pincher, a self-hosted spend tracker, is a Go API with a SQLite database, described by an OpenAPI spec that a React web app and a native SwiftUI Mac client both build against. Macpardy, a trivia-night host for the Mac, has phone buzzers that talk to it over WebSocket on the local network.

Knowing what's on the other side of the API makes me a better iOS engineer. I can read a contract critically, ask for the endpoint the screen actually needs, and tell whether a problem belongs to the client or the server.
