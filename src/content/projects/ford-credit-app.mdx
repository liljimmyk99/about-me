## The pregame

A large mobile app is only as healthy as the foundation under it. When I joined the Ford Credit mobile platform team in 2024, the job was to give the app's feature teams shared, consistent building blocks.

## The playbook

- A SwiftUI design system, built from scratch, with the design and product teams working with me to drive component adoption.
- Mobile deployment pipelines and workflows, maintained in GitHub Actions and Bitrise.
- Team standards in Jira, GitHub and documentation, and every Scrum ceremony facilitated for the team.
- A Development Style Guide, plus GitHub Copilot instructions that review pull requests and request changes when code doesn't conform to it.

## My role

I started on the platform team in January 2024 as both a mobile platform engineer and the technical project manager. In January 2025 I became an iOS software engineer on the app itself. Lately that work has centered on standardizing the codebase: writing the style guide, setting up automated review against it, and using AI to refactor existing code to match.

## Film review

Writing standards down is only half the job; they stick when review enforces them where the code is already being discussed. Putting the style guide in front of Copilot on every pull request made it part of the daily workflow instead of a document people had to remember.
