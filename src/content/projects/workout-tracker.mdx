## The pregame
Currently I track my workouts in Apple Notes which is fine and dandy.  However, as I cycle through different workouts if I am able to increase a weight for a given exercise that is not easily able to be reflect across all workouts that include that exercise.  I want a way that when I increase my working weight for a given exercise, it will be reflected in any workout I intend to do for that day and going forward.

## Scouting Report
There are some apps out there, but they cost money and have features I don't care out.  If I am going to be renting a VPS or local hosting apps already, then why not create my own app that I control, can personalize, and enhance as I please!
